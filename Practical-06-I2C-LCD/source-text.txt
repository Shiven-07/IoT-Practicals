5. Procedure
i) Enable I2C Interface on Raspberry Pi by writing below code in command terminal
sudo raspi-config
ii) Navigate:
Interface Options
→ I2C
→ Enable
iii) Reboot Raspi by writing below code in command terminal
sudo reboot
iv) Install I2C Tools by writing below code in command terminal
sudo apt update
sudo apt install -y i2c-tools python3-smbus

Verify whether LCD is detected
sudo i2cdetect -y 1
Expected Output:
0123456789abcdef
20:-- -- -- -- -- -- 27 -- -- -- -- --
Note: The LCD address is typically Ox27 or Ox3F,
